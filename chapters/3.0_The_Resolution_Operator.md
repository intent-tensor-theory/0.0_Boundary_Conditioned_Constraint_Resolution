# 章三・零 (Chapter 3.0)

## Boundary-Conditioned Resolution

---

**「見えるものは、解かれたものだ。」**
*What is seen is what has been resolved.*

---

### 3.0.1 The Central Mathematical Object

We now introduce the core formalism of this framework:

**The Boundary-Conditioned Constraint Resolution Operator**

```
R_B[Φ] → Ψ
```

Where:
- Φ = constraint field (imposed by object)
- B = admissibility boundary (surface conditions)
- Ψ = resolved appearance (what is seen)
- R_B = resolution operator (the process)

---

### 3.0.2 Formal Definition

**Definition (Resolution Operator):**

> R_B is an operator that takes a constraint field Φ and an admissibility boundary B, and produces a resolved appearance Ψ.

```
R_B : Φ → Ψ

Subject to:
  1. R_B preserves topological invariants of Φ
  2. R_B depends on local properties of B
  3. R_B is computed at the boundary, not transmitted to it
```

---

### 3.0.3 What "Resolution" Means

Resolution is **not**:
- Copying
- Storing
- Transmitting
- Representing

Resolution **is**:
- Determining which configurations are admissible given B
- Selecting the configuration that satisfies Φ under B's constraints
- Producing an appearance Ψ from this selection

Think of it like solving an equation:
- Φ provides the structure
- B provides the boundary conditions
- Ψ is the solution

---

### 3.0.4 The Two-Boundary Case (Reflection)

For reflection, we have:

```
Object appearance  = R_B₁[Φ]   where B₁ = air boundary
Reflection         = R_B₂[Φ]   where B₂ = water surface

Same Φ.
Different B.
Different Ψ.
```

**This is why they match:**

Both are resolutions of the **same** constraint field.

The "impossible synchronization" is not impossible at all.
It is tautological.
Of course R_B₁[Φ] and R_B₂[Φ] are related—they share Φ.

---

### 3.0.5 Why Inversion Occurs

The water surface (B₂) has different admissibility conditions than air (B₁).

Specifically, B₂ enforces:
- Specular geometry (angle of incidence = angle of reflection)
- Vertical inversion (normal to surface)
- Horizontal preservation (parallel to surface)

These are properties of **B**, not Φ.

```
Φ contains the structure
B₂ transforms how that structure resolves
Inversion emerges from the geometry of B₂
```

---

### 3.0.6 Mathematical Properties of R_B

**Property 1: Identity Under Trivial Boundary**

If B imposes no constraints:
```
R_∅[Φ] = Φ   (trivial resolution)
```

**Property 2: Composition**

Multiple boundaries compose:
```
R_B₂[R_B₁[Φ]] = R_{B₁∘B₂}[Φ]
```

**Property 3: Topological Preservation**

R_B preserves topological invariants:
```
Topology(R_B[Φ]) ≅ Topology(Φ)

Provided B is continuous and well-posed.
```

**Property 4: Locality**

R_B is computed locally at B:
```
R_B[Φ](x) depends only on Φ near x and B at x
```

---

### 3.0.7 The Resolution Equation

We can write the resolution process as an equation:

```
Find Ψ such that:

1. Ψ is admissible under B
2. Ψ is compatible with Φ
3. Ψ is unique (well-posed boundary problem)

Then: Ψ = R_B[Φ]
```

This is analogous to solving a boundary value problem in differential equations.

---

### 3.0.8 What R_B Explains

| Phenomenon | Explanation |
|------------|-------------|
| Reflection exists | R_B₂[Φ] ≠ 0 when B₂ is reflective |
| Reflection matches object | Same Φ |
| Inversion occurs | B₂ geometry enforces it |
| Distortion under ripples | B(t) varies |
| Identity persists | Topological invariants preserved |

---

### 3.0.9 What R_B Does NOT Require

The resolution operator does **not** require:

- Light to "carry" the image
- Surface to "store" the image
- Information to "travel" from object to surface
- Observer to "interpret" the result

R_B is a structural relationship, not a communication protocol.

---
