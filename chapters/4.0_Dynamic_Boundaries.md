# 章四・零 (Chapter 4.0)

## Dynamic Boundaries

---

**「水は止まらない。だが、像は残る。」**
*Water never stops. Yet the image remains.*

---

### 4.0.1 The Liquid Surface Problem

A mirror is simple:
- B is static
- B is planar
- R_B[Φ] is constant

A liquid surface is complex:
- B(t) varies continuously
- B(t) is non-planar
- R_B(t)[Φ] varies continuously

Yet identity persists.

**This chapter explains how.**

---

### 4.0.2 Time-Varying Boundaries

Let B(t) denote a time-dependent boundary.

For a liquid surface:
```
B(t) = B₀ + δB(t)

Where:
  B₀ = mean surface level
  δB(t) = perturbation (waves, ripples)
```

The resolution becomes:
```
Ψ(t) = R_B(t)[Φ]
```

The appearance changes continuously.
But is identity preserved?

---

### 4.0.3 Stability Conditions

Identity is preserved if and only if:

**Condition 1: Continuity of B(t)**
```
B(t) must be continuous (no tears in the surface)
```

**Condition 2: Bounded Gradient**
```
|∇B(t)| < ∞ (no infinitely steep waves)
```

**Condition 3: Topological Preservation**
```
B(t) must be homotopic to B₀ (no topology change)
```

Under these conditions:
```
Topology(R_B(t)[Φ]) ≅ Topology(Φ)   ∀t
```

Identity persists.

---

### 4.0.4 What Changes, What Remains

Under smooth B(t) variation:

| Property | Changes? |
|----------|----------|
| Exact positions | Yes |
| Line shapes | Yes |
| Local angles | Yes |
| Adjacency | No |
| Continuity | No |
| Part-whole | No |
| Topology | No |

**Geometry varies. Topology is invariant.**

This is why ripples distort but do not destroy.

---

### 4.0.5 The Threshold Phenomenon

There exists a critical threshold.

Below threshold:
- B(t) perturbations are smooth
- R_B(t)[Φ] distorts but preserves identity
- Observer recognizes the same object

Above threshold:
- B(t) becomes turbulent
- Continuity breaks
- Topology changes
- R_B(t)[Φ] fragments
- Identity is lost

```
∃ ε_critical such that:

|δB(t)| < ε_critical → identity preserved
|δB(t)| > ε_critical → identity lost
```

This explains the sharp transition from "distorted reflection" to "chaos."

---

### 4.0.6 No Storage Required

The key insight:

**The water surface stores nothing.**

At each instant t:
- B(t) is the current boundary configuration
- R_B(t)[Φ] is computed fresh
- No memory of previous instants is required

The reflection is **recomputed**, not **replayed**.

```
Ψ(t) = R_B(t)[Φ]    computed at time t
Ψ(t+dt) = R_B(t+dt)[Φ]    computed at time t+dt

No information passes from Ψ(t) to Ψ(t+dt)
Both are independent resolutions of the same Φ
```

---

### 4.0.7 Why Synchronization Is Perfect

The "impossible synchronization" is now explained:

When the object moves:
- Φ changes to Φ′
- R_B(t)[Φ′] immediately reflects this

When the water moves:
- B(t) changes to B(t′)
- R_B(t′)[Φ] immediately reflects this

There is no lag because there is no transmission.
Both object and reflection are resolutions of the same field.
"Synchronization" is the wrong word.
**They were never separate.**

---

### 4.0.8 The Dynamics Equation

We can write the full dynamic system:

```
Given:
  Φ(t) = constraint field (may vary if object moves)
  B(t) = boundary (varies as water moves)

Then:
  Ψ(t) = R_B(t)[Φ(t)]

With stability condition:
  d/dt Topology(Ψ(t)) = 0    when |∇B(t)| < threshold
```

---

### 4.0.9 Comparison: Static vs Dynamic

| Aspect | Static (Mirror) | Dynamic (Water) |
|--------|-----------------|-----------------|
| Boundary | B = constant | B(t) varies |
| Resolution | R_B[Φ] = constant | R_B(t)[Φ] varies |
| Geometry | Preserved | Distorted |
| Topology | Preserved | Preserved (below threshold) |
| Storage | Not needed | Not needed |
| Computation | Once | Continuous |

The framework handles both with the same operator.
Dynamic is not a special case—it is the general case.
