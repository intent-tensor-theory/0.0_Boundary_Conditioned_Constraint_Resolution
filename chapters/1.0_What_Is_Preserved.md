# 章一・零 (Chapter 1.0)

## What Is Preserved in Reflection

---

**「同じに見える。だが、何が同じなのか。」**
*It looks the same. But what exactly is the same?*

---

### 1.0.1 The Empirical Starting Point

Before formalizing, we must observe precisely what reflection actually preserves.

This is not philosophy. This is measurement.

---

### 1.0.2 Preserved Properties

**1. Relational Identity**

The reflected tree is recognizably the same tree.

Not "similar." Not "corresponding." **The same.**

This identity persists even under:
- Motion of the object
- Motion of the observer
- Motion of the surface

**2. Topological Correspondence**

- Adjacency is preserved (what was next to what remains next to what)
- Continuity is preserved (no gaps appear)
- Ordering is preserved (left-right, up-down relationships maintain)

**3. Systematic Inversion**

- Vertical flip (consistent, predictable)
- Angle preservation (geometry maintained)
- Chirality reversal (left becomes right)

**4. Stability Under Smooth Deformation**

Small ripples **distort** the reflection but do not **destroy** it.

There exists a threshold below which identity persists.
Above that threshold, coherence breaks.

---

### 1.0.3 What Is NOT Preserved

**1. Exact Geometry**

Ripples deform shapes. Curves appear. Straight lines bend.

Yet identity persists.

**2. Pixel-Level Correspondence**

There is no point-to-point mapping that remains fixed.

Yet identity persists.

**3. Static Form**

The reflection is in constant flux.

Yet identity persists.

---

### 1.0.4 The Puzzle Sharpened

We now see the puzzle precisely:

> **Identity persists despite continuous geometric deformation.**

This cannot be explained by:

- Signal copying (what is copied changes constantly)
- Storage (where would it be stored?)
- Transmission (what travels between object and reflection?)

Something else is happening.

---

### 1.0.5 The Key Observation

What persists is not **form**.

What persists is **relational structure**.

```
The tree has branches in certain relations to each other.
The reflection preserves those relations.
The specific geometry of each branch varies with ripples.
But the relations between branches remain.
```

This is the first clue.

**Identity is relational, not geometric.**

---

### 1.0.6 Invariants Under Transformation

We can now list the invariants precisely:

| Property | Preserved? |
|----------|------------|
| Point positions | No |
| Line shapes | No |
| Exact angles | No |
| Adjacency relations | Yes |
| Continuity | Yes |
| Topological ordering | Yes |
| Part-whole structure | Yes |

The preserved properties are **topological invariants**.

---

### 1.0.7 Why This Matters

If identity is topological rather than geometric, then:

- No exact copying is required
- No storage is required
- Only relational structure must be preserved

This points toward constraint preservation, not signal transmission.

---

### 1.0.8 Transition

We have identified **what** is preserved.

Now we must ask: **what kind of field** could carry this structure?

The answer: not a signal field.

A **constraint field**.

---

**「形は変わる。関係は残る。」**
*Form changes. Relations remain.*
