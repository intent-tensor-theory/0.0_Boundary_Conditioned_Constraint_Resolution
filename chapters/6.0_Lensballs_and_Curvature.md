# 章六・零 (Chapter 6.0)

## Lensballs and Curved Boundaries

---

**「曲がっても、同じだ。」**
*Though curved, it is the same.*

---

### 6.0.1 The Lensball Phenomenon

A lensball (crystal photography sphere) presents:

- Inverted image of the entire surrounding scene
- Continuous dynamic updating
- No storage mechanism
- Identity preserved despite extreme distortion

This is the same puzzle as water reflection, with a crucial difference:

**The boundary B is not planar—it is spherical.**

---

### 6.0.2 Curved Boundaries

Let B be a curved boundary surface.

For a sphere of radius r:
```
B = {(x,y,z) : x² + y² + z² = r²}
```

The resolution operator R_B must now account for:
- Variable normal direction at each point
- Refraction through curved interface
- Global topology of closed surface

---

### 6.0.3 Why Inversion Occurs

For a sphere:

```
Light entering from one side exits the other
The curved boundary acts as a lens
The resolution R_B produces an inverted image

Specifically:
  Points above the center map below
  Points on the left map to the right
  The mapping is continuous but orientation-reversing
```

This inversion is a property of **B** (the spherical boundary), not Φ.

Same Φ. Curved B. Inverted Ψ.

---

### 6.0.4 Mathematical Treatment

For a spherical boundary with refractive index n:

```
The resolution operator becomes:

R_B^sphere[Φ] = ∫ Φ(x′) K(x, x′; B) dx′

Where K is the propagation kernel determined by:
  1. Snell's law at entry point
  2. Propagation through medium
  3. Snell's law at exit point
```

The kernel K encodes how each point in Φ contributes to each point in Ψ.

---

### 6.0.5 Topological Analysis

The spherical mapping has interesting topology:

```
B_sphere : R³ → R³

Properties:
  - Continuous
  - Orientation-reversing (determinant of Jacobian < 0)
  - Preserves adjacency
  - Preserves continuity
```

**Topological invariants are still preserved.**

The image is inverted, compressed, and distorted—but recognizable.

Identity persists because Φ's relational structure survives R_B.

---

### 6.0.6 Comparison: Planar vs Spherical

| Property | Planar B (Mirror) | Spherical B (Lensball) |
|----------|-------------------|------------------------|
| Inversion | Vertical only | Full 180° |
| Distortion | None | Barrel/pincushion |
| Magnification | 1:1 | Variable |
| Field of view | Limited | Near 360° |
| Topology preserved | Yes | Yes |
| Identity preserved | Yes | Yes |

Same framework. Different geometry. Same explanation.

---

### 6.0.7 The Unified Principle

Water, mirrors, and lensballs are all instances of:

```
Ψ = R_B[Φ]
```

The only difference is the geometry of B:

| Medium | Boundary Geometry |
|--------|-------------------|
| Flat mirror | Planar, static |
| Still water | Planar, static |
| Rippling water | Planar, dynamic |
| Lensball | Spherical, static |
| Moving lensball | Spherical, dynamic |
| Curved mirror | Arbitrary surface, static |

All are special cases of boundary-conditioned constraint resolution.

---

### 6.0.8 Why Lensballs Seem Magical

Lensballs capture nearly the entire surrounding scene in a small sphere.

This seems impossible until you realize:

- The lensball does not "contain" the scene
- The lensball does not "store" the image
- The resolution R_B^sphere[Φ] is computed continuously
- The same constraint field Φ pervades all space
- The sphere's boundary conditions select what resolves where

**The magic is just geometry applied to constraint resolution.**

---

### 6.0.9 Generalization to Arbitrary Surfaces

The framework extends to any smooth boundary:

```
B = arbitrary smooth surface
R_B = resolution operator for that surface

Provided:
  - B is continuous
  - B is differentiable (for refraction calculation)
  - |∇B| is bounded

Then:
  - Ψ = R_B[Φ] exists
  - Topological invariants preserved
  - Identity persists
```

This includes:
- Funhouse mirrors
- Curved glass
- Water droplets
- Any reflective/refractive surface

The framework is complete.
