### 7.0.2 The Answer

**The reflection is not copying anything.**

There is no movie. There is no transmission. There is no storage.

There is ONE constraint field Φ being resolved through TWO different admissibility boundaries simultaneously.

```
Object you see     = R_B₁[Φ]    (resolution through air)
```

The synchronization is tautological.
The "impossible movie" is not a movie at all.
Nothing is recorded. Nothing is played back.
The resolution is computed fresh every instant—and since Φ is invariant, the result is coherent.
