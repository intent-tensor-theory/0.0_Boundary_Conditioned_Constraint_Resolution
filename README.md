# 📘 Boundary-Conditioned Constraint Resolution

**Resolution Without Representation**

A Pre-Geometric Account of Reflection, Refraction, and Identity Preservation

## 「水面は真似をしない。制約を共有する。」
*The surface does not imitate. It shares constraint.*

---

## The Original Question

> How does the surface of water generate a DYNAMIC constant state of flux like this? The inverse opposite of what it is facing. The reflection watches everything and copies its movements in real time. Like a movie. This is impossible.

This repository contains the mathematical answer.

---

## Central Thesis

**A reflection is not a copy. It is the same constraint field resolved through a different admissibility boundary.**

```
Object you see     = R_B₁[Φ]    (resolution through air)
Reflection you see = R_B₂[Φ]    (resolution through water surface)

Same Φ. Different B. No copying. No storage. No transmission.
```

The synchronization is not mysterious—it is tautological.
The "impossible movie" is not a movie at all.
Nothing is recorded. Nothing is played back.
The resolution is computed fresh every instant.

---

## Why Identity Persists

Because identity IS the constraint pattern, not the resolved image.

```
B(t) varies continuously     → water moves
R_B(t)[Φ] varies continuously → reflection distorts

But topological invariants of Φ are preserved
until boundary perturbations exceed critical threshold
```

Small ripples distort but do not destroy.
The constraint field has not changed.
Only the boundary has.

## The Core Mathematical Objects

| Symbol | Name | Meaning |
|--------|------|---------|
| Φ | Constraint Field | Relational structure imposed by stable object |
| B | Admissibility Boundary | Surface conditions (water, glass, mirror) |
| R_B[Φ] | Resolution Operator | What you actually see |
| B(t) | Dynamic Boundary | Time-varying surface |
| Ψ | Resolved Appearance | Output of R_B[Φ] |

---

## The Core Equation

```
R_B[Φ] → Ψ

Where:
  Φ  = constraint field (not light, not signal)
  B  = admissibility boundary
  Ψ  = resolved appearance

For reflection:
  R_B_air[Φ]   = object appearance
  R_B_water[Φ] = reflection

Same Φ. Different B. Identity preserved.
```

## Why This Is New

Classical optics tells you:
- The angles (Snell's Law)
- The intensities (Fresnel equations)
- The interference patterns

Classical optics does NOT tell you:
- Why the reflected tree is recognizably the same tree
- Why identity persists under dynamic boundary deformation
- Why there is no storage yet perfect synchronization

**This framework answers those questions.**

---

## Relation to Classical Optics

This framework **subsumes** classical optics, not replaces it.

When B is:
- static
- planar
- isotropic

...then R_B reduces to ray-based or wave-based formulations.
Snell and Fresnel emerge as special cases.
